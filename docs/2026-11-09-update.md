# 2026-11-09 工程更新

本次同步正念、音乐和暴露三个实验场景，以及问卷交互、移动端渲染与音频资源。

## 问卷和虚化

- 所有实验组的离散选项统一使用约 0.45 秒沉降反馈，移除中央选中亮点与选中色闪。沉降后的状态保持，单选、多选和翻页记录保留。
- 世界空间问卷文字提高字体采样密度；Mobile URP 使用原生渲染比例 1，保留 2× MSAA。
- C/F 组背景在 3 秒内渐进虚化，色彩处理状态保持一致；手柄射线在清晰 UI 叠加层绘制。
- Android 植被与草地绘制范围收紧。清晰度提升、常驻调色和手柄叠加相机也有成本，需要在设备上确认整体帧预算。

## 音乐疗法

- 停用导入资源残留的五个垃圾桶层级。
- 根据实际地形高度和树冠包围范围重算路线，清除通道内侵入的树木。保守静态树冠净空最小约 1.533 米；风摆、用户身体偏移及其他障碍仍需实际检查。
- 树木从 10,548 棵减至 5,516 棵，减少密集重叠。森林会更稀疏、开阔。
- 新路线长度约 46.636 米，与原路线相同；沿累计距离运动，保持原音乐时长、往返规则与移动速度节奏。

## 暴露疗法

- 远端任务文字复用中文 SDF 字体，并随距离调整大小、朝向玩家；桥上三个标记横向错开。
- 自定义桥面 Shader 补齐 XR 单通道实例化的双眼阶段支持。
- 916 个栏杆、立柱改用已有不透明材质并标记静态，启用 Android 静态批处理；玻璃桥面保留，透明渲染器从 924 个降至 8 个。
- 导入地面原先用普通网格材质且没有地形层，现运行时转换为兼容实例化的 URP 地形材质，沿用原沥青纹理。退出场景时释放临时资源并恢复引用。
- 裁剪屏幕占比很小的远处人物，停止视野外人物动画与蒙皮；建筑、桥梁和高度锚点保留。
- 转层淡入使用黑色遮罩。

桥面双眼 Shader 和地形实例化不匹配是闪屏排查中发现的明确问题；尚无设备复现证据证明它们解释了全部彩色闪屏。
